Binary Search Trees & AVL Trees

A BST keeps values ordered for efficient search; an AVL tree keeps that search path short by rebalancing.

01 Binary Search Trees

Recap

A binary search tree (BST) stores each node so that every value in its left subtree is smaller and every value in its right subtree is larger. To search or insert, compare once at each visited node and continue down just one branch.

The work is O(h), where h is the tree height: O(log N) when the tree is balanced, but O(N) when it becomes a chain.

Visual · Search for 23

        20
       /  \
     10    30
    / \    / \
   5  15  23  40
          ^

23 > 20  → go right
23 < 30  → go left
23 = 23  → found

Pseudocode

contains(node, x):
    while node is not null:
        if x < node.key:
            node = node.left
        else if x > node.key:
            node = node.right
        else:
            return true
    return false

insert follows the same comparisons,
then attaches a new leaf at a null link.

Textbook basis: Sections 4.1–4.3, including Section 4.3, “The Search Tree ADT—Binary Search Trees.”

02 AVL Trees

Recap

An AVL tree is a BST that maintains balance after insertions and deletions. At every node, the heights of the left and right subtrees differ by at most one. This keeps the height O(log N), so searching, inserting, and removing are all O(log N).

When a node becomes unbalanced, a rotation changes the local shape while preserving the BST ordering rule.

Visual · Left-Left imbalance

Before insertion       After right rotation
      30                       20
     /                        /  \
   20                        10  30
  /
10

The subtree stays in sorted order:
10, 20, 30

Rotations

balance = height(left) - height(right)

balance = +2  (left heavy)
  left-left  → rotate right
  left-right → rotate left on left child,
               then rotate right

balance = -2  (right heavy)
  right-right → rotate left
  right-left  → rotate right on right child,
                then rotate left

Textbook basis: Section 4.4, “AVL Trees,” especially Sections 4.4.1–4.4.2 on single and double rotations.
