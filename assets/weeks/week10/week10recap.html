CSCI 3333 · Week 10

Shortest Paths & Network Flows

A compact review of Bellman–Ford, maximum flow, bipartite perfect matching, and Edmonds–Karp.

01 Bellman–Ford

Recap

Bellman–Ford finds shortest-path distances from one start vertex even when some edges have negative weights. Its invariant is that after pass i, every shortest path using at most i edges has been considered.

Visual · Relax an edge

s --(4)--> a --(-2)--> b
direct distance to b: 5

known: dist[a] = 4
candidate through a: 4 + (-2) = 2
update: dist[b] = min(5, 2) = 2

Pseudocode

set dist[start] = 0; all other distances = infinity

repeat |V| - 1 times:
    for every edge (u, v) with weight w:
        dist[v] = min(dist[v], dist[u] + w)

make one more pass:
    if any distance improves:
        a reachable negative cycle exists

It runs in O(|V||E|). A negative cycle reachable from the start means some destinations have no finite shortest distance.

02 Network Flows

Recap

A flow network sends as much as possible from source s to sink t. Each edge has a capacity, no edge may exceed it, and every non-source/non-sink vertex preserves flow: what enters must leave.

Visual · One augmenting path

s --3--> a --2--> t

bottleneck = min(3, 2) = 2
send 2 units:  s ==2==> a ==2==> t
remaining forward capacity: 1, 0
residual reverse capacity:  2, 2

Core idea

The residual graph records what is still possible. A forward residual edge has unused capacity; a reverse residual edge permits canceling earlier flow so the algorithm can change its mind. When no residual path from s to t remains, the current flow is maximum and the reachable vertices define a minimum cut.

Textbook basis: Section 9.4, “Network Flow Problems.”

03 Perfect Matching

Recap

A matching chooses edges so no vertex is used twice. In a bipartite graph, a perfect matching pairs every vertex on both sides exactly once. A maximum matching can be found with max flow.

Visual · Convert matching to flow

source --(1)--> L1 --(1)--> R1 --(1)--> sink
                |          |
            (1) |          | (1)
                v          v
                L2 --(1)--> R2

Every edge has capacity 1.
A unit of flow L1 --> R1 means: match L1 with R1.

Check

Connect the source to each left vertex and each right vertex to the sink with capacity 1. Give each allowed left-to-right pairing capacity 1. The flow value equals the number of pairs. With N vertices on each side, the matching is perfect exactly when the maximum flow is N.

04 Edmonds–Karp

Recap

Edmonds–Karp is Ford–Fulkerson with one important rule: use breadth-first search to choose an augmenting path with the fewest edges in the residual graph.

Pseudocode

while BFS finds a path from s to t:
    b = path's smallest residual capacity
    subtract b forward; add b backward
    total flow += b

Why BFS helps

Each BFS is O(|E|). Choosing shortest augmenting paths bounds the number of augmentations, giving Edmonds–Karp a running time of O(|V||E|²). It still relies on reverse residual edges: a later path may need to reroute earlier flow.

Textbook basis: Section 9.4, “Network Flow Problems,” for residual graphs and augmenting paths.
