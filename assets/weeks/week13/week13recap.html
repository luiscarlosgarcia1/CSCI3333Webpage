Dynamic Programming

Solve each smaller subproblem once, save its answer, and build toward the final one.

01 The Dynamic Programming Idea

Recap

Dynamic programming applies when a problem has overlapping subproblems: a recursive solution asks for the same smaller answer again and again. Instead, solve each subproblem once and save the result.

Find a state that describes a smaller version of the problem, write a recurrence that connects states, set the base cases, then compute the states in an order that makes their dependencies available.

Visual · Repeated work

Naive recursion for F(5)

          F(5)
         /    \
      F(4)    F(3)
      /  \    /  \
   F(3) F(2) F(2) F(1)

F(3) and F(2) are needed more than once.
DP computes each once, saves it, then reuses it.

02 From Recurrence to Table

Recurrence

F(0) = 0
F(1) = 1
F(n) = F(n - 1) + F(n - 2)

The recurrence says what a state needs. Because F(n) depends on two smaller states, fill values from small n to large n.

Pseudocode · Bottom-up

dp[0] = 0
dp[1] = 1

for n from 2 to N:
    dp[n] = dp[n - 1] + dp[n - 2]

return dp[N]

A table replaces the recursion tree. This version takes Θ(N) time and Θ(N) space; because only the two previous values are needed, the space can be reduced to Θ(1).

Textbook basis: Section 10.3, “Dynamic Programming.”

03 Application: Longest Common Subsequence

Recap

A subsequence keeps characters in their original order but may skip characters. For strings X and Y, let dp[i][j] be the LCS length of their first i and j characters.

Visual · One table

X = A B C D       Y = A C B D

      ∅  A  C  B  D
  ∅   0  0  0  0  0
  A   0  1  1  1  1
  B   0  1  1  2  2
  C   0  1  2  2  2
  D   0  1  2  2  3

One LCS has length 3: A B D

Recurrence

if X[i - 1] == Y[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + 1
else:
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

Matching characters extend a smaller answer. Otherwise, keep the better result after skipping one final character. The table takes Θ(MN) time and space.
