CSCI 3333 · Week 06

Tries

A prefix tree stores words one character at a time, making shared beginnings and prefix searches easy to follow.

01 The Prefix-Tree Idea

Recap

A trie stores a set of strings by putting one character on each edge. The root represents the empty string, and the path from the root to any node spells a prefix. A node needs an isWord marker because a word can end while longer words continue from that same node.

Visual · Store to, tea, ten, and ted

root
└── t
    ├── o  • word: to
    └── e
        ├── a  • word: tea
        ├── d  • word: ted
        └── n  • word: ten

The node for t + e is only a prefix.
The node for t + o is both a prefix and word.

Key invariant

At every step, choose the child whose edge matches the next character. If that child does not exist, the requested word or prefix is not in the trie. The work depends on the word length L, so lookup and insertion are O(L).

Textbook basis: Section 12.4.2, “Suffix Trees” (pp. 583–584), which introduces basic and compressed tries.

02 Lookup, Insertion, and Removal

Recap

Lookup and insertion both walk one edge per character. Lookup succeeds only when the final node is marked as a complete word; insertion creates only the missing part of the path, then marks the last node. To remove a word, clear its ending marker and prune upward only while a node has no children and is not another word’s ending.

Visual · Search for ten

start at root
  read t  → follow t
  read e  → follow e
  read n  → follow n
  at n and isWord is true → "ten" is stored

Example · Remove ted

Before: te → d  • word: ted

Clear d.isWord.
The d node has no children, so remove it.
Work our way back up the path.
At e, stop pruning becaues e still has children (a and n)

After removal: tea and ten remain; ted is gone.

03 Prefixes

Recap

A prefix is the beginning of one or more stored words. To autocomplete a prefix, follow its path first, then traverse every descendant below that node. Each terminal node reached gives one completion.

Visual · Complete te

Follow the prefix: root → t → e

Traverse below e:
  e → a  • word: tea
  e → d  • word: ted
  e → n  • word: ten

Completions for "te": tea, ted, ten

Example

Tries are useful when many words share beginnings and the question is about prefixes: autocomplete, dictionaries, spell checking, or finding all words that start with a query.

04 Operations Pseudocode

Recap

All three basic operations first follow the word’s character path. The final action determines whether the trie checks, adds, or removes the word.

Pseudocode

contains(word):
    node = root
    for each ch in word:
        if node has no child ch: return false
        node = node.child[ch]
    return node.isWord

insert(word):
    node = root
    for each ch in word:
        if node has no child ch: create it
        node = node.child[ch]
    node.isWord = true

remove(word):
    follow the word's path; if it is not a word, stop
    clear the final node's isWord marker
    remove nodes upward while they have no children and are not words
