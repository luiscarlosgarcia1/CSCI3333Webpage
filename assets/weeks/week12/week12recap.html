CSCI 3333 · Week 12

Divide and Conquer

A concise review of recurrences, faster multiplication, worst-case linear selection, and unequal-size recursive calls.

01 Divide and Conquer & the Master Theorem

Recap

Divide and conquer solves smaller, disjoint subproblems recursively, then combines their answers. For a recurrence T(N) = aT(N/b) + Θ(Nk), compare the number of subproblems, a, with bk: the amount of work represented by the recursive levels.

Visual · One recurrence tree

T(N) = 2T(N/2) + Θ(N)

level 0:       Θ(N)
level 1:   2 × Θ(N/2) = Θ(N)
level 2:   4 × Θ(N/4) = Θ(N)
...
log₂ N levels, each costing Θ(N)

total: Θ(N log N)

Master theorem

T(N) = aT(N/b) + Θ(Nᵏ)

a > bᵏ  → Θ(N^(log_b a))  recursive work dominates
a = bᵏ  → Θ(Nᵏ log N)      every level balances
a < bᵏ  → Θ(Nᵏ)            combine work dominates

For merge sort, a = 2, b = 2, and k = 1, so a = bk and the time is Θ(N log N).

Textbook basis: Section 10.2.1, “Running Time of Divide-and-Conquer Algorithms.”

02 Master Theorem · Multiple Sizes

Recap

When recursive calls have different size fractions, the ordinary aT(N/b) form does not fit. Use a characteristic equation to find the exponent created by all recursive calls together.

Characteristic equation

T(n) = c nᵅ logᵝ n + Σ aᵢT(⌈bᵢn⌉)
                         0 < bᵢ < 1

g(x) = Σ aᵢbᵢˣ
find r such that g(r) = 1

Then compare r with α.

Result

r > α  → T(n) = Θ(nʳ)
r = α  → T(n) = Θ(nᵅ log^(β+1) n)
r < α  → T(n) = Θ(nᵅ logᵝ n)

Selection example:
T(n) = T(n/5) + T(7n/10) + Θ(n)

g(1) = 1/5 + 7/10 = 9/10 < 1
so r < 1 = α, and T(n) = Θ(n).

The last line agrees with the median-of-medians analysis above. The handout’s theorem is the source for this unequal-subproblem version.

Handout basis: “Multiple-Size Divide-and-Conquer Recurrences,” Theorem 1.

03 Linear-Time Selection

Recap

Selection asks for the kth smallest element without fully sorting the collection. Median-of-medians chooses a pivot that is guaranteed to discard a constant fraction of the elements, giving worst-case linear time.

Visual · Median of medians

Split into groups of 5; find each group median.

[ 2  7  9 12 18 ] →  9
[ 1  4 10 11 20 ] → 10
[ 3  5  6 15 19 ] →  6
             ...

pivot = median of the medians
partition around pivot; recurse only where k lies

Why the recurrence is linear

T(N) ≤ T(N/5) + T(7N/10) + Θ(N)

median of medians: at most N/5 items
after partitioning: at most about 7N/10 items

1/5 + 7/10 = 9/10 < 1
so the total work is Θ(N)

The algorithm makes one recursive call to find the pivot and one recursive call on the side containing the desired rank. It does not recurse on both partitioned sides.

Textbook basis: Section 10.2.3, “The Selection Problem.”

04 Karatsuba Integer Multiplication

Recap

Splitting two N-digit numbers into high and low halves appears to need four half-size products. Karatsuba gets the middle term from one extra product plus additions, so it makes only three recursive multiplications.

Visual · The three products

x = x₁Bᵐ + x₀        y = y₁Bᵐ + y₀

p = x₁y₁              q = x₀y₀
r = (x₁ + x₀)(y₁ + y₀)

xy = pB²ᵐ + (r - p - q)Bᵐ + q

The middle coefficient uses r - p - q,
not two separate cross products.

Recurrence

T(N) = 3T(N/2) + Θ(N)

a = 3, b = 2, k = 1
3 > 2¹

T(N) = Θ(N^(log₂ 3)) ≈ Θ(N^1.59)

The ordinary digit-by-digit method takes Θ(N²). Karatsuba trades arithmetic additions and subtractions for one fewer recursive multiplication.

Textbook basis: Section 10.2.4, “Multiplying Integers.”

05 Strassen Matrix Multiplication

Recap

Split each N × N matrix into four N/2 × N/2 quadrants. The direct block formula needs eight recursive matrix multiplications. Strassen rearranges sums and differences so that seven are enough.

Visual · Block multiplication

      [ A11  A12 ] [ B11  B12 ]
AB =  [ A21  A22 ] [ B21  B22 ]

C11 = A11B11 + A12B21

Direct recursion: 8 half-size products
Strassen:         7 half-size products
                + Θ(N²) block additions

Recurrence

T(N) = 7T(N/2) + Θ(N²)

a = 7, b = 2, k = 2
7 > 2²

T(N) = Θ(N^(log₂ 7)) ≈ Θ(N^2.81)

This beats the usual Θ(N³) bound asymptotically. The savings come from replacing one expensive recursive matrix product with cheaper block additions and subtractions.

Textbook basis: Section 10.2.4, “Matrix Multiplication.”
