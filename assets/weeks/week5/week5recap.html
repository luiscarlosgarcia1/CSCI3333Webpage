CSCI 3333 · Week 05

AVL Rotations

The four local reshapes that restore AVL balance while keeping the binary-search-tree order intact.

01 AVL Rebalancing

Recap

Insertion first works down the tree exactly like a normal binary-search-tree insertion: compare the new value at each node and follow the left or right child until it reaches an empty position. Then the recursive calls return upward along that same path.

On the way back up, each visited node checks the heights of its left and right subtrees. If their difference becomes greater than one, that node is rebalanced with the matching rotation. P is the parent above the affected subtree; after the rotation, P points to the subtree’s new top node.

Every diagram preserves the in-order sequence, so it also preserves the BST rule. The case name describes the two directions from the unbalanced node: LL, RR, LR, or RL.

Visual · The local view

Only this link above the subtree changes:

         (P)                       (P)
          |                         |
 subtree root  becomes | subtree's new top node

Everything outside this small subtree is unchanged.

Key idea

The taller inside or outside path is shortened by moving its middle node upward. A node that moves down keeps the child subtree whose values still belong on that side of it.

Textbook basis: Section 4.4, “AVL Trees,” especially Sections 4.4.1–4.4.2 on single and double rotations.

02 Left-Left (LL)

Recap

A is too heavy on the left, and its left child B is also heavy on the left. B becomes the top of this subtree. A moves down to become B’s right child.

Visual · Right rotation at A

Before                                      After
              (P)                                      (P)
               |                                        |
              (A)                                      (B)
             /   \                                    /   \
           (B)   (N)                                (BL)  (A)
           / \                                      /    / \
        (BL) (BR)                                  (N) (BR) (N)
        /
      (N)

The path A → B → N → N is two levels longer than A → N.
B rotates up and takes A as its right child. B’s right child, BR, is
now between B and A, so A adopts BR as its left child.

03 Right-Right (RR)

Recap

A is too heavy on the right, and its right child B is also heavy on the right. B becomes the top of this subtree. A moves down to become B’s left child.

Visual · Left rotation at A

Before                                      After
              (P)                                      (P)
               |                                        |
              (A)                                      (B)
             /   \                                    /   \
           (N)   (B)                                (A)  (BR)
                 / \                                / \    \
              (BL) (BR)                           (N) (BL)  (N)
                     \
                     (N)

The path A → B → N → N is two levels longer than A → N.
B rotates up and takes A as its left child. B’s left child, BL, is
now between A and B, so A adopts BL as its right child.

04 Left-Right (LR)

Recap

A is left-heavy, but its left child B is right-heavy. The middle node, C, becomes the new top. It directly takes B and A as its children, making the subtree balanced again.

Visual · C rises above B and A

Before                                      After
              (P)                                      (P)
               |                                        |
              (A)                                      (C)
             /   \                                    /   \
           (B)   (N)                                (B)   (A)
           / \                                      / \   / \
         (N) (C)                                 (N)(CL) (CR)(N)
             / \
          (CL) (CR)

The path A → B → C is two levels longer than A → N.
C rotates up and takes B and A as its children. C’s left child, CL, is
adopted by B, and C’s right child, CR, is adopted by A.

05 Right-Left (RL)

Recap

A is right-heavy, but its right child B is left-heavy. The middle node, C, becomes the new top. It directly takes A and B as its children, making the subtree balanced again.

Visual · C rises above A and B

Before                                      After
              (P)                                      (P)
               |                                        |
              (A)                                      (C)
             /   \                                    /   \
           (N)   (B)                                (A)   (B)
                 / \                                / \   / \
               (C) (N)                           (N)(CL) (CR)(N)
              / \
            (CL)(CR)

The path A → B → C is two levels longer than A → N.
C rotates up and takes A and B as its children. C’s left child, CL, is
adopted by A, and C’s right child, CR, is adopted by B.
