Network Flows & Perfect Matching

A concise review of residual networks, bipartite perfect matching, and the Edmonds–Karp maximum-flow algorithm.

01 Network Flows

Recap

A flow network sends as much as possible from source s to sink t. Every edge has a capacity, and its flow cannot exceed that capacity. At each vertex other than s and t, flow is conserved: the amount entering equals the amount leaving.

Visual · Augmenting a path

s --3--> a --2--> t

residual capacities on this path: 3, 2
bottleneck = min(3, 2) = 2

send 2 units:
s ==2==> a ==2==> t

remaining forward capacity: 1, 0
new reverse residual capacity: 2, 2

Core idea

The residual graph shows what can change. A forward residual edge represents unused capacity; a reverse residual edge allows an earlier choice to be undone and rerouted. If no residual path from s to t remains, the flow is maximum.

Textbook basis: Section 9.4, “Network Flow Problems.”

02 Perfect Matching

Recap

A matching selects edges so that no vertex appears in more than one selected edge. In a bipartite graph, a perfect matching gives every vertex on the left and every vertex on the right exactly one partner.

Visual · Turn matching into flow

source    left     right      sink
  s --1--> L1 --1--> R1 --1--> t
   \         \--1--> R2
    \--1--> L2 --1--> R2

Every edge has capacity 1.
One unit on L1 --> R1 means: match L1 with R1.

Check

Connect s to each left-side vertex, every allowed left-to-right pairing, and each right-side vertex to t; give every edge capacity 1. The maximum-flow value is the number of matched pairs. If there are N vertices on each side, the matching is perfect exactly when the maximum flow is N.

03 Edmonds–Karp

Recap

Edmonds–Karp is Ford–Fulkerson with a fixed path rule: use breadth-first search to find an augmenting path with the fewest edges in the residual graph.

Pseudocode

maxFlow = 0

while BFS finds a residual path from s to t:
    b = smallest residual capacity on the path
    subtract b from forward residual edges
    add b to reverse residual edges
    maxFlow += b

return maxFlow

Why BFS matters

Each BFS takes O(|E|). Choosing shortest augmenting paths bounds the number of augmentations, so Edmonds–Karp runs in O(|V||E|²). The reverse residual edges are essential: a later augmenting path may reroute flow chosen earlier.

Textbook basis: Section 9.4, “Network Flow Problems.”
