Shortest Paths: Dijkstra

Dijkstra’s algorithm repeatedly finalizes the closest unvisited vertex to find shortest paths from one start vertex.

01 Dijkstra’s Algorithm

Recap

Dijkstra’s algorithm solves the single-source shortest-path problem in a weighted graph whose edge weights are nonnegative. It keeps a best-known distance for every vertex. At each step, it chooses the unvisited vertex with the smallest tentative distance; that distance is then final.

The key operation is relaxing an edge: if reaching v through u is shorter than the current route to v, replace dist[v] and remember u as its predecessor.

Choose D: E=6

Choose C: F=8
Choose E: F=min(8, 6+1)=7

Final distances from A: 
  A=0, B=4, C=5, D=1, E=6, F=7

Pseudocode

dijkstra(G, start):
    for each vertex v:
        dist[v] = ∞
        prev[v] = none
    dist[start] = 0
    add all vertices to a min-priority queue

    while queue is not empty:
        u = remove vertex with smallest dist
        for each edge (u, v) with weight w:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
                update v in the queue

    return dist, prev

With an adjacency list and a binary-heap priority queue, the running time is O((V + E) log V). Follow the prev links backward from a destination to rebuild its shortest path.

Textbook basis: Section 9.3.2, “Dijkstra’s Algorithm.”
